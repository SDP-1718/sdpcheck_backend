# 푸시 토큰 등록·삭제

FCM에서 받은 기기별 푸시 토큰을 회원과 연결해 PostgreSQL에 저장한다. 등록·삭제 API는 MEMBER 또는 ADMIN의 Bearer 토큰이 필요하다.

## API 흐름

1. 프론트가 FCM에서 현재 기기의 토큰을 획득하고 `POST /api/v1/devices/push-tokens`에 `{"token":"..."}`을 전송한다. 서버는 200 응답의 `result.tokenId`로 등록 행의 ID를 반환한다.
2. 같은 토큰을 다시 등록하면 기존 ID를 유지한다. 다른 회원이 같은 토큰을 등록하면 현재 회원으로 연결을 변경한다. 휴대폰과 컴퓨터처럼 서로 다른 토큰은 각각 저장한다.
3. `DELETE /api/v1/devices/push-tokens/{tokenId}`는 현재 회원 소유의 해당 등록만 삭제하고 204를 반환한다. 요청·성공 응답 본문은 없다. 없는 토큰, 이미 삭제된 토큰, 다른 회원의 토큰은 모두 404다.

## 주의 사항

토큰은 필수이며 최대 512자이고 공백을 포함할 수 없다. 입력 오류는 400, 인증 누락·토큰 검증 실패는 401, 회원 권한 부족은 403이다. `tokenId`는 DB의 숫자 ID이며 FCM 토큰 문자열과 다르다.

삭제 API는 우리 DB의 연결만 제거하고 Firebase의 토큰 자체를 폐기하지 않는다. 로그아웃 API는 푸시 토큰을 자동 삭제하지 않는다. 프론트는 인증 가능한 상태에서 삭제 API를 호출하고, 현재 브라우저의 푸시 구독은 Firebase `deleteToken()`으로 해제한다. 삭제 실패 때문에 로그아웃을 막지 않는다.

알림 설정 OFF는 토큰 삭제와 별개다. 실제 알림 발송과 FCM 무효 토큰 자동 정리는 후속 작업이다. 저장소와 중복 방지·회원 FK는 Flyway V10으로 반영한다.
