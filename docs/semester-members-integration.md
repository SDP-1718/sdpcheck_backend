# 학기별 회원 명단 통합

PR #43(홈), #44(관리자 통계)는 `feat/#31-my-attendance-summary-api`에
병합되어 develop에는 포함되지 않았습니다. 해당 브랜치를 develop에 통합합니다.

## 마이그레이션 번호

- V9: 카카오 회원 온보딩 (기존 파일 보존)
- V10·V11: 푸시 토큰·알림 설정 작업 브랜치에서 사용 중이므로 예약
- V12: semesters.period_code (기존 중복 V9에서 이동)
- V13: semester_members (기존 V10에서 이동)
- V14: study_sessions 일정 컬럼 (세션 브랜치의 중복 V9에서 이동)
- V15: 결석 출석 기록 허용 (세션 브랜치의 중복 V10에서 이동)

학기별 회원 마이그레이션 테스트는 V12까지의 기존 데이터에 V13을 적용하고,
출석 기록 보존·자동 명단 생성 없음·복합 키 및 외래 키 제약을 검증합니다.
새 DB는 develop의 현재 파일만으로도 순서대로 생성할 수 있습니다.

기존 공유 DB에 이전 번호의 학기 코드 또는 명단 마이그레이션을 적용했다면,
배포 전에 flyway_schema_history와 실제 스키마를 확인하고 별도의 전환 절차를
협의해야 합니다. 자동 repair, 이력 삭제, DB 초기화는 수행하지 않습니다.

## 온보딩 연결

members.generation은 회원 기수이며 semester_members는 학기별 소속 명단입니다.
후속 온보딩 변경에서는 현재 운영 학기(is_current = true)에 자동 등록하며,
회원 저장과 명단 등록을 하나의 트랜잭션으로 처리합니다.
운영 학기가 없으면 온보딩을 완료하지 않습니다. 세부 계약은 kakao-auth.md를 참고합니다.

## 세션 출석 대상

세션 시작 시 해당 세션 학기의 semester_members 중 MEMBER 권한 회원을 출석 대상으로
등록합니다. 학기가 지정되지 않은 세션은 현재 운영 학기 명단을 사용합니다.
명단은 자동으로 채워지지 않으므로, 온보딩 이전에 가입한 회원은 별도로 등록해야 합니다.
